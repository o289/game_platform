# ボードゲームプラットフォーム

## 技術

### 言語:

TypeScript

### フレームワーク

- React,
- Node.js,
- Express.js,
- tailwindcss: v4系を使用

バージョンの違いによる設定方法の差が大きい場合は明示

### socket

Socket.IO

### トンネルサービス

cloudflareトンネル

### その他

- Docker
- ESLint

### 備考

- "module": "commonjs"を活用

今回は言語をサーバー、クライアントで統一する
また、開発者のPCがスリープ時は遊べなくする予定なのでトンネルサービスはngrokを採用

## 各ディレクトリの役割

### 非機能

1. core
   ゲーム、ルーム、ソケットなどのプラットフォームに関わるコードやライブラリを配置

2. Games
   各ゲームの動作に関するコードを配置。配下にゲーム名ディレクトリを作成

3. app
   実際に動作させる。core, Gamesのゲームの部品を組み合わせる

**coreの機能をgem_nameでも使用できるようにする**

### 機能

1. client
   フロントエンドに関わるものを配置。coreではルーム作成、待機部屋、プレイゲーム選択画面などを配置、GameNameではそのゲームに関するUIを配置

2. server
   サーバーに関わるものを配置。クライアント同様のことをサーバーでも行う

3. shared
   共通で使用する型定義を配置。クライアント同様のことをサーバーでも行う

4. test
   テストに関するものを配置

5. script
   シェルに関するものを配置

6. docs
   ドキュメントの置き場所。ルートにのみ配置しgit ignoreする

7. public
   画像や音声データを配置。GameNameにのみ配置
